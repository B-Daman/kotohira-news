# assets/manual/ — ニュース・イベント用の手動画像（画像の“正”）

サイトの**ニュース・イベント**に表示する画像は、**このフォルダに置いたファイルが最優先**です。
Notion は画像に使いません（表示バグ・URL失効があり信用しないため）。

## assets/links/ との違い

このフォルダ（`assets/manual/`）は、Notion由来のニュース・イベントのサムネイルが無い／間違っている
場合に、`image-overrides.json` のマッチングで上書きするための画像置き場。一方 `assets/links/`
は**🔗リンクタブ専用**のサムネイル置き場で、こちらは `image-overrides.json` の仕組みは使わず、
`links-data.js` の各リンクエントリの `image` キーに直接パスを書く手編集運用（Notion連携なし）。
どちらも「画像はローカルが正」というlocal-first方針は共通だが、対象タブと運用の仕組みが違うため
混同しないこと。

## 使い方
1. `C:\Users\user\Downloads\琴平町イベント画像` などから、使いたい画像を
   このフォルダ（`assets/manual/`）にコピーする（ファイル名は自由。分かりやすい名前推奨）。
2. リポジトリ直下の `assets/image-overrides.json` に「どの項目にどの画像を出すか」を書く。
   - キー … その項目の **出典URL**（`http…`）、または **タイトルの一部**（空白区切りで複数語＝すべて含む項目にマッチ）
   - 値 … このフォルダ内のファイル名
3. `python scripts/fetch_notion.py` を実行 → マッチした項目はこの画像を使い、
   **Notionからは一切取得しません**（ログに「ローカル画像を◯件適用（Notion非経由）」と出ます）。
4. 画像ファイルと `image-overrides.json` を git にコミットすれば、公開サイトでも確実に出ます。

## 例（image-overrides.json）
```json
{
  "https://www.instagram.com/p/XXXX/": "kimono14.jpg",
  "夏のお茶会 藤田屋": "chakai_fujitaya.png"
}
```

- マッピングに無い項目は、従来どおり Notion の画像を試します（段階的に移行できます）。
- 指定したファイルがこのフォルダに無いと、fetch 実行時に警告が出ます（空表示に気づけるように）。

## 誤マッピングに注意（実例: もくもくAI作業会）

タイトルの部分一致（空白区切り語のAND）でマッチさせる方式のため、似た名前の別イベントに
別イベントの画像を割り当ててしまう誤爆が起こり得る。実際に「もくもくAI作業会」という項目に
`mokumoku_ai.png` を割り当てていたが、その画像は実は別イベント（初心者向けAIセミナー）の
チラシで、誤マッピングだったため削除した（2026-07-09〜10）。もくもく本来の画像はNotion側の
サムネイルをそのまま使う運用に戻し、`assets/thumbs/` から配信される。`mokumoku_ai.png`
ファイル自体はこのフォルダに残置してあり、今後AIセミナー系のイベントが登録された際に
そのイベント用の override として転用できる。新しくマッピングを追加・変更するときは、
ファイル名だけで判断せず、画像の中身が本当にそのイベントのものか目視で確認すること。
