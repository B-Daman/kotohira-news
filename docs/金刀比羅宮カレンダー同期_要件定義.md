## 1. 目的

金刀比羅宮の行事を、公式が公開している Google カレンダー（こんぴらさんカレンダー）を正本として Notion イベントDBへ自動で揃え、DAO の Discord「イベント情報」フォーラムへの投稿まで人手を要らなくする。

いま人手でやっていること（なくす対象）:

1. 公式サイトの年間行事ページから1年分を写す（年1回・時刻が13件しか載っていない）
2. 各行事の時刻を Google カレンダーで見て Notion に入れる
3. Notion の formula「投稿文」をコピーしてフォーラムに投稿し、スレッド URL を「DiscordイベントURL」に貼る（52件が未投稿）

## 2. 本人の裁定（この要件の根拠）

## 3. 現状の事実（11/5 調査）

### 3-1. 公式カレンダー（入力）

- 公開 ICS（ログイン不要）: `https://calendar.google.com/calendar/ical/64b68ef555a41f2caf5f34f93acba872a95083434d72ca613eae03a38907f6e5%40group.calendar.google.com/public/basic.ics`
- 117 VEVENT・73KB。繰り返し 86 件（FREQ=YEARLY／YEARLY;BYDAY=3MO;BYMONTH=7／MONTHLY;BYMONTHDAY）、EXDATE 24、RECURRENCE-ID 6、TZID=Asia/Tokyo
- ほぼ全件に開始・終了時刻。LOCATION 104 件（御本宮・神事場・奥社・白峰神社…）、DESCRIPTION 61 件（祭典の説明文）、URL は無し
- 2026-01〜2027-03 に展開すると 133 回。月次祭は毎月 1・6・10・26 日 9:00〜9:30（3月は系列の重なりで同日重複あり）

### 3-2. Notion イベントDB（出力先）

- 「カレンダー」に 金刀比羅宮 を持つページ 71 件（11/5 時点）。うち DiscordイベントURL 無し 52、開催場所（relation）無し 48、主催/運営 無し 20
- 11/5 に公式カレンダーと突合し、一致 46 件のうち時刻が無かった 23 件へ公式の時刻を入れた（紅葉祭 10:00〜10:30 など）
- 題名の表記違いで一致しなかった組（厳魂神社（奥社）例祭↔厳魂神社大祭、藻刈潮汲神事↔潮汲藻刈神事 など）と、年間行事ページにしか無い神事（御蔵開神事・口明神事 など 25 件）がある。**どちらにも片方だけのものがあるので併用する**
- 開催場所は場所DB（会場名・住所・GoogleマップURL）への relation。金刀比羅宮（御本宮）・神事場・嚴魂神社（奥社）・白峰神社・旭社 のページがある

### 3-3. 既存の仕組み（乗る先）

- 書き込みトークンは本人 PC の資格情報（登録スキル `kotohira-news-register`）にだけある。GitHub Actions は読み取り専用 → **同期は日曜の週次ラン（akki-staff `run_weekly.bat`・07:30・30分上限）で回す**。こんぴらカレンダーの `towncal_register.py` と同じ乗り方
- 登録スキルの設定 `config-events-konpira.json`（既定: カレンダー=金刀比羅宮・市町村=琴平町）が既にある。relation は登録スキルでは書けない（別途 PATCH）
- konpie-bot（Railway）は `NEWS_NOTION_TOKEN` でイベントDBにページを作れる（登録ch）。フォーラム投稿のコードは無い。discord.py 2.3 以上なので `ForumChannel.create_thread` が使える。機能は「環境変数が無ければ無効」が規約
- Notion の formula「投稿文」「Discord用タイトル」を API で読むと UTC・英語曜日になる → **日時は bot が JST で組み立てる**

## 4. 要件A: 公式カレンダー → Notion 同期（週1回）

| # | 要件 |
|---|---|
| A-1 | 公開 ICS を取得する。取得できなければ何もせず「取得失敗」を報告する |
| A-2 | 対象の窓は **今日〜90日先**。過去の行事は見ない・触らない（年末に翌年1月分が自然に窓へ入る） |
| A-3 | 繰り返しを展開する（YEARLY／MONTHLY;BYMONTHDAY／YEARLY;BYDAY+BYMONTH、UNTIL、EXDATE、RECURRENCE-ID）。同じ日・同じ題名は1つに畳む |
| A-4 | Notion との突合は **同じ日 ＋ 似た題名**（正規化して一致／3字以上の内包／一致率 0.8 以上）または **別名規則**（人が育てる表）で「同じ行事」とみなす |
| A-5 | 同じ行事なら **空欄だけ補う**: 開始・終了時刻、カレンダー=金刀比羅宮、開催場所、主催/運営、ソース。入っている値は上書きしない。時刻が食い違えば「要確認」に出す |
| A-6 | 同じ行事が無く、同じ日に未一致の神社ページ（カレンダーか主催に金刀比羅宮）も無ければ **新規登録**（イベント名・開始・終了・カレンダー=金刀比羅宮・市町村=琴平町・主催/運営=金刀比羅宮・ソース=公式カレンダーページ・コメント=説明文＋場所＋出典・開催場所）。同じ日に未一致の神社ページがあれば登録せず **要確認**（規則で「別の行事」と決めてあれば登録する） |
| A-7 | 月次祭は **回ごとに Notion の行**を作る（週間スケジュールと ICS に出すため）。フォーラム投稿は要件B で1つにまとめる |
| A-8 | 記録: 取得した ICS の写し、別名・場所の規則、今回の結果（登録・補完・要確認）をリポジトリに残し commit・push する |
| A-9 | 日曜レポートに1行（登録 n・補完 n・要確認 n・参照先） |
| A-10 | 守ること: 削除しない、既存値を上書きしない、既定は dry-run、トークンの値を出さない、同じ日の既存ページは題名の短さに関わらず人に見せる（11/5 の教訓） |

## 5. 要件B: フォーラム自動投稿（konpie-bot・毎日）

| # | 要件 |
|---|---|
| B-1 | 対象: カレンダーに 金刀比羅宮 を持ち、DiscordイベントURL が空で、開始日が **今日〜14日先** のページ |
| B-2 | **同じ題名の再利用**: 直近45日〜窓内に同じ題名で URL 済みのページがあれば、新しく投稿せずその URL を書き戻す（月次祭＝投稿1つ）。フォーラムに同名のスレッドが既にあればそれを使う（投稿後に書き戻しが失敗した回の保険） |
| B-3 | 投稿の形は本人の手順と同じ: スレッド名「MM/DD(曜)HH:MM～HH:MM 題名」、本文「## ✅題名／・日時／市町村：場所／住所：[住所](地図URL)／参加費／説明／URL」。日時は JST・日本語曜日で bot が組む。時刻の無いページは日付だけ |
| B-4 | 投稿できたらスレッド URL を DiscordイベントURL に書く（これが「投稿済み」の印。ローカルの状態ファイルは持たない） |
| B-5 | 1回に投稿するのは最大5件（初回に溜まった分が一度に流れないため）。残りは翌日 |
| B-6 | 有効化は `EVENT_FORUM_CHANNEL_ID`（フォーラムのチャンネル ID）が設定されたときだけ。未設定＝無効でログに1行。`EVENT_FORUM_DRY_RUN=true` で投稿せず内容だけログ |
| B-7 | 守ること: 投稿したスレッドを編集・削除しない、URL 済みのページに触らない、管理者以外が動かせる入口を作らない |

## 6. 本人の作業（後で手順書にする）

1. Railway の konpie-bot の Variables に `EVENT_FORUM_CHANNEL_ID`（イベント情報フォーラムのチャンネル ID）を入れる。入れるまで投稿機能は動かない
2. そのフォーラムで こんぴーくん に「投稿を作成」「スレッドでメッセージを送信」の権限があるか確認する

## 7. 既定で進める点（本人の異論があれば変える）

- 月次祭の Notion 行は回ごと（週間スケジュールに「09:00- 月次祭」が月4回出る）。1つの定数で止められる
- 参加費は入れない（公式に記載が無いため。bot の投稿では参加費の行を省く）
- 2027年1月分は同期が先に作るので、本人は年始の手入力をしなくてよい。年間行事ページにしか無い神事（口明神事など）は従来どおり年1回の手確認
- 同期は金刀比羅宮だけが対象。基本のイベント・こんぴらカレンダーの投稿は従来どおり人手（対象の拡大は別の裁定）

## 8. 検証・Definition of Done

- 同期: dry-run で「登録・補完・要確認」の内訳が説明できる → apply → Notion で紅葉祭・月次祭・2027-01 歳旦祭の行を目視 → 週間スケジュールの harness で時刻つきで出る
- bot: 日時整形と本文組み立ての単体テスト（JST・日本語曜日・時刻なし・複数日）、再利用規則のテスト、`EVENT_FORUM_DRY_RUN=true` で本番 Notion に対し投稿内容をログ確認 → 本人が ID を入れて初回投稿
- 日曜レポートに1行出る（verify スクリプトの単体実行で確認）
